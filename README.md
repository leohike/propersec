# lazypass

Your Linux account password is a crucial piece of your computer security and privacy and there is an inherent dilemma in it: truly strong password should be long and random so it is a hassle to type and short or non-random password is not secure. We have traditional UX vs security dilemma. People end up using weak passwords or write them down on pieces of paper, often stored right next to their computers.

Specialized hardware keys offer some improvement both for security and UX when configured correctly, but they have own drawbacks, both UX and security wise.
